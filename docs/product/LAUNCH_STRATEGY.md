# Stratégie de lancement Kop

> Plan d'action pour le lancement public de l'app (V1.0, prévu T3 2026).

---

## 🎯 Objectifs du lancement

**Objectif principal**
Atteindre **1 000 téléchargements actifs** dans les 30 jours suivant le lancement, avec un taux de rétention J7 > 30%.

**Objectifs secondaires**
- Récolter au moins 50 retours qualitatifs utilisateurs
- Obtenir 4.5+ étoiles sur les stores
- Construire une petite communauté (500 followers sur les réseaux)

---

## 📅 Phases de lancement

### Phase 0 — Pré-lancement (1 mois avant)

**Objectifs** : créer l'attente, identifier les bêta-testeurs.

- [ ] Création des comptes réseaux : Instagram, Twitter/X, TikTok (@kopapp)
- [ ] Landing page simple (Framer ou Vercel) avec waitlist email
- [ ] Premier teaser vidéo (15 sec, ambiance + logo)
- [ ] Recruter 20-30 bêta-testeurs proches (TestFlight + Expo)
- [ ] Itérer sur les retours bêta

### Phase 1 — Soft launch (jour J)

**Objectifs** : publier sans grand bruit, vérifier que tout fonctionne.

- [ ] Publication App Store + Play Store
- [ ] Annonce discrète : story Instagram, tweet, post LinkedIn perso
- [ ] Partage dans les groupes WhatsApp/Discord foot
- [ ] Mention sur Reddit r/ligue1, r/soccer, r/footballfrance

### Phase 2 — Push communauté (J+7)

**Objectifs** : faire connaître au-delà du cercle proche.

- [ ] Vidéo démo TikTok (60 sec, montre les features)
- [ ] Carrousel Instagram "10 raisons d'utiliser Kop"
- [ ] Article Medium / dev.to : "J'ai créé mon app foot, voici comment"
- [ ] Contact micro-influenceurs foot (10k-50k abonnés)
- [ ] Posts sur ProductHunt si timing pertinent

### Phase 3 — Itération et croissance (J+30)

**Objectifs** : améliorer le produit selon les retours, scaler.

- [ ] Analyse des analytics (rétention, écrans visités, friction)
- [ ] Mise à jour majeure avec features demandées
- [ ] Partenariats : blogs foot, podcasts spécialisés
- [ ] A/B testing sur le store listing

## 💰 Budget alloué

Projet bootstrap, budget zéro hors investissements obligatoires :

- Apple Developer Account : 99 € / an
- Google Play Developer Account : 25 € (one-shot)
- Domaine landing : ~12 € / an
- Notion / Figma : versions gratuites
- Bouts d'IA pour génération musique/voix off : ~30 € (Suno + ElevenLabs gratuit)

**Total** : ~150 € pour le lancement.

Pas de pub payante en V1 (organique uniquement).

## 📊 KPIs à suivre

### Acquisition
- Téléchargements / jour
- Sources d'acquisition (organic, social, referral)
- Taux de conversion store listing → install

### Engagement
- DAU / MAU (utilisateurs quotidiens / mensuels)
- Sessions par utilisateur
- Temps moyen passé dans l'app
- Écrans visités (top 5)

### Rétention
- D1, D7, D30 retention
- Taux de désinstallation

### Qualité
- Notes app store
- Volume et tonalité des reviews
- Reports de bugs

### Outils
- **Analytics intégré Expo** (basique)
- **PostHog** ou **Mixpanel** (V1.1 si besoin de plus de profondeur)
